# Behavioral Economics Code

This repository supports the Behavioral Economics knowledge series with reproducible, article-level research scaffolds. It is designed for transparent modeling, synthetic-data demonstrations, economic reasoning, behavioral policy analysis, and computational workflows.

## Repository scope

The repository includes article-specific folders with synthetic datasets, documentation, model scaffolds, causal-inference examples, behavioral-friction simulations, welfare calculations, decision-regime models, and reproducible code across languages useful to economists and computational social scientists.

## Responsible use

These examples are educational and research-scaffolding tools. They are not fitted to confidential or proprietary data, and they should not be used as operational policy tools without empirical validation, sensitivity analysis, peer review, and appropriate ethical governance.
