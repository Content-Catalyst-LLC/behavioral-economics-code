# Behavioral Economics Code

Computational companion repository for the Behavioral Economics knowledge series.

This repository supports article-level folders, reproducible examples, synthetic datasets, documentation, decision-regime simulations, behavioral-friction models, prospect-theory examples, intertemporal-choice workflows, social-preference models, policy-uptake simulations, platform-behavior scaffolding, and scientific-computing workflows across Python, R, Julia, C++, Fortran, C, Rust, SQL, Go, and notebooks where appropriate.

## Repository structure

```text
articles/               Article-level folders
_shared/                Shared reusable examples and modeling workflows
data/synthetic/         Synthetic datasets only
docs/                   Documentation, methods, ethics, and scope notes
outputs/                Generated figures and tables
scripts/                Utility scripts
```

## Scope

The examples in this repository use synthetic data and simplified models. They are intended for education, research scaffolding, methodological demonstration, and reproducible analysis. They are not decision tools for targeting, manipulating, profiling, or exploiting people.

## Main workflow themes

- Classical and behavioral decision-regime comparison
- Prospect-theory value functions
- Intertemporal-choice and present-bias examples
- Default effects and choice architecture
- Social-preference and cooperation models
- Policy-uptake and administrative-friction simulations
- Platform-behavior scaffolding
- Transparent synthetic data and reproducible documentation
