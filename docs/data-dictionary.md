# Data Dictionary

| Field | Meaning |
|---|---|
| agent_id | Synthetic decision-maker identifier |
| regime | Simulated decision environment |
| framing_signal | Synthetic framing effect input |
| loss_signal | Synthetic loss-aversion or reference-dependence input |
| time_signal | Synthetic intertemporal-choice input |
| social_signal | Synthetic social influence or norm input |
| trust_signal | Synthetic institutional trust input |
| default_status | Whether an option is selected by default |
| effort_cost | Simulated administrative or cognitive burden |
| choose_option | Binary synthetic choice outcome |
| uptake_probability | Modeled probability of adopting, enrolling, or choosing |
