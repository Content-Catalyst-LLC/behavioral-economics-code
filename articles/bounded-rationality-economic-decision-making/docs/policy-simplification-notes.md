# Policy Simplification Notes

Policy simplification applies bounded-rationality insights to public access, service design, and institutional fairness.

## Tools

- automatic enrollment
- prefilled forms
- plain language
- mobile-friendly application
- multilingual support
- human navigators
- fewer documentation steps
- single application portals
- deadline reminders
- status transparency
- appeal rights
- proactive outreach

## Evaluation

A good policy-simplification workflow should measure:

- take-up
- completion
- comprehension
- time burden
- user dignity
- error correction
- distributional access
- long-term welfare
- administrative cost
- trust
