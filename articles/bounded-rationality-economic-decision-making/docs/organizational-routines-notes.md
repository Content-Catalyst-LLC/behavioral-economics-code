# Organizational Routines Notes

Organizations manage bounded rationality through routines, procedures, roles, dashboards, metrics, committees, reporting systems, and delegated authority.

## Benefits

- reduce cognitive burden
- preserve organizational memory
- coordinate action
- standardize quality
- reduce uncertainty
- make complex operations feasible

## Risks

- path dependence
- stale assumptions
- metric fixation
- rigid procedures
- blind spots
- information filtering
- suppression of frontline knowledge

## Good design

- feedback loops
- error reporting
- revisable routines
- frontline input
- institutional memory
- adaptive governance
- clear escalation pathways
- learning-oriented metrics
