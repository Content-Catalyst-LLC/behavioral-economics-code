# Administrative Burden Notes

Administrative burden includes learning costs, compliance costs, and psychological costs.

## Learning costs

- discovering that a program exists
- determining eligibility
- understanding rules
- interpreting technical language
- comparing options
- finding deadlines

## Compliance costs

- collecting documents
- completing forms
- attending appointments
- verifying identity
- navigating websites
- responding to repeated requests
- waiting

## Psychological costs

- stigma
- fear
- shame
- distrust
- frustration
- cognitive fatigue
- anxiety

## Policy implications

Administrative burden can reduce take-up, reproduce inequality, and convert formal rights into inaccessible rights.

## Evaluation metrics

- completion rate
- take-up rate
- drop-off point
- processing time
- error rate
- appeal rate
- comprehension
- user burden
- distributional access
