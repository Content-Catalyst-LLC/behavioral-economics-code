# Bounded Rationality Theory Notes

## Core idea

Bounded rationality means that rational decision-making is constrained by finite attention, memory, computation, information, time, and institutional context.

## Full optimization

```text
x* = argmax V(x_i)
```

## Satisficing

```text
choose x_i when V(x_i) >= a
```

where `a` is an aspiration threshold.

## Search-cost-adjusted value

```text
U(x_i) = V(x_i) - c s_i
```

where `c` is search cost and `s_i` is the number of inspected options.

## Interpretation

Satisficing may be welfare-relevant and adaptive when search costs are high, feedback is noisy, options are uncertain, and time is scarce.

## Caution

Bounded rationality should not be used to blame people for decisions made under scarcity, stress, institutional distrust, discrimination, or administrative burden.
