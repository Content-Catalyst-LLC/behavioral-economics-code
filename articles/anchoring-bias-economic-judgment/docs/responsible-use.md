# Responsible Use

Appropriate uses include behavioral-economics teaching, benchmark-design research, consumer-protection analysis, wage-transparency analysis, housing-appraisal research, negotiation education, digital-platform governance review, sustainability-baseline analysis, public-policy evaluation, and synthetic simulation.

Inappropriate uses include deceptive reference pricing, manipulative salary anchoring, misleading monthly-payment framing, inflated discount anchors, exploitative negotiation scripts, algorithmic estimate laundering, predatory lending anchors, or using behavioral insights to bypass informed judgment.

All outputs are synthetic. They should not be interpreted as legal advice, financial advice, investment advice, real-estate advice, wage advice, product recommendations, or empirical claims about real consumers, workers, investors, housing markets, platforms, agencies, or public audiences.
