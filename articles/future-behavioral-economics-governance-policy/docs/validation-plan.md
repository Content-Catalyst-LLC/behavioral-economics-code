# Validation Plan

For real research use, this scaffold would need validation steps such as:

1. Specify the policy context and target behavior.
2. Define whether the outcome is enrollment, compliance, retention, uptake, appeal, or behavioral persistence.
3. Replace synthetic data with documented empirical data only where lawful and ethical.
4. Assess measurement validity for trust, burden, salience, and compliance.
5. Test sensitivity to model assumptions.
6. Compare average effects with distributional effects.
7. Evaluate unintended consequences and legitimacy risks.
8. Document limitations clearly.

No file in this scaffold should be used for operational decisions about individuals.
