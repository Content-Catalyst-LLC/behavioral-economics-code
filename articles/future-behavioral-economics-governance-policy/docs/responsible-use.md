# Responsible Use

This article scaffold supports synthetic-data research and reproducible learning about behavioral economics in governance and policy.

Appropriate uses include:

- public-policy education
- synthetic scenario analysis
- computational methods demonstration
- governance research prototyping
- reproducible documentation practice

Inappropriate uses include:

- individual compliance scoring
- surveillance or behavioral targeting
- automated eligibility decisions
- enforcement prioritization
- coercive behavioral manipulation
- dark-pattern design
- production deployment without legal, ethical, and empirical review

Behavioral-governance work should protect autonomy, transparency, equity, contestability, and public legitimacy.
