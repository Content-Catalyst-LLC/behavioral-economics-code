# Responsible Use

This scaffold supports synthetic-data research and reproducible learning about behavioral economics and digital platforms.

Appropriate uses include:

- applied behavioral-economics teaching
- platform-economics methods demonstration
- consumer-protection research scaffolding
- platform-governance analysis
- welfare-analysis prototyping
- recommendation-system audit design
- reproducible documentation practice

Inappropriate uses include:

- manipulative ranking optimization
- addictive engagement design
- coercive personalization
- surveillance
- dark-pattern development
- privacy-hostile consent design
- operational user scoring
- production deployment without legal, ethical, accessibility, and empirical review

Platform behavioral research should protect autonomy, contestability, privacy, accessibility, transparency, worker voice, market fairness, and user welfare.
