# Robustness and Sensitivity Plan

Professional nudge-policy workflows should include robustness checks.

## Recommended checks

1. Estimate treatment effects with and without covariates.
2. Compare OLS models with logit/probit for binary adoption where appropriate.
3. Estimate heterogeneous effects by present-bias quartile.
4. Estimate heterogeneous effects by administrative-burden-sensitivity quartile.
5. Estimate heterogeneous effects by default-sensitivity quartile.
6. Estimate heterogeneous effects by trust quartile.
7. Test alternative user-benefit weights.
8. Test alternative social-benefit weights.
9. Test alternative friction-cost and administrative-cost assumptions.
10. Compare adoption effects with welfare effects.
11. Report standard errors and confidence intervals where packages are available.

## Placebo checks for real data

- Pre-treatment program take-up.
- Prior appointment attendance.
- Baseline filing or compliance behavior.
- Baseline trust or program awareness.
- Pre-treatment communication exposure.

## External validity

Real nudge effects depend on domain, stakes, institutional trust, population, baseline burden, language access, digital access, eligibility rules, implementation quality, and the legitimacy of the underlying policy. Synthetic results should not be interpreted as real-world estimates.
