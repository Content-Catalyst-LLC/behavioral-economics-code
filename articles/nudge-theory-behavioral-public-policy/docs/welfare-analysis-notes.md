# Welfare Analysis Notes

Nudge policy should not be evaluated only by uptake, clicks, attendance, compliance, consent, or enrollment. Behavior change is not automatically welfare improvement.

## Welfare components

The synthetic workflows define total welfare as a function of:

- user benefit from adoption
- social benefit from adoption
- friction cost
- administrative cost
- implementation cost
- present-bias and burden heterogeneity
- distributional incidence across user groups

## Welfare accounting

A stylized welfare expression is:

```text
W = utility + user_benefit + social_benefit - friction_cost - administrative_cost - implementation_cost
```

## Key diagnostic

A useful diagnostic is whether the ranking of interventions differs when judged by uptake versus welfare. If one nudge increases adoption but performs poorly on welfare, it should be interpreted cautiously.
