# Responsible Use

This scaffold supports synthetic-data research and reproducible learning about nudge theory and behavioral public policy.

Appropriate uses include:

- applied behavioral-economics teaching
- policy-evaluation methods demonstration
- welfare-analysis prototyping
- benefit take-up and administrative burden research
- public-health reminder analysis
- environmental nudge evaluation
- tax-compliance and public-service communication research
- reproducible documentation practice

Inappropriate uses include:

- dark-pattern design
- manipulative defaults
- deceptive disclosure
- extractive consent architecture
- targeting vulnerable users for behavioral exploitation
- replacing public justification with invisible steering
- production deployment without legal, ethical, accessibility, distributional, and empirical review

Behavioral public policy should support transparency, accessibility, reversibility, proportionality, informed agency, institutional accountability, and welfare-enhancing governance.
