# Validation Plan

For real research use, this scaffold would need validation steps such as:

1. Specify the interface context and target behavior.
2. Define whether the outcome is conversion, retention, cancellation, consent, sharing, engagement, or welfare.
3. Replace synthetic data with documented empirical data only where lawful, ethical, and appropriate.
4. Assess whether observed behavior reflects user welfare, confusion, habit, lock-in, or coercive friction.
5. Test sensitivity to model assumptions.
6. Compare average effects with heterogeneous effects across overload, privacy sensitivity, disability, language, and digital literacy.
7. Evaluate unintended consequences and manipulation risk.
8. Document limitations clearly.

No file in this scaffold should be used for manipulative design optimization or operational user targeting.
