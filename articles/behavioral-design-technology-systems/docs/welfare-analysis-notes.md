# Welfare Analysis Notes

Behavioral design should not be evaluated only by conversion or retention. A system can raise retention by creating value, but it can also raise retention through exit friction, confusion, default lock-in, or cognitive fatigue.

## User welfare proxy

The synthetic workflows define user welfare as a function of:

- baseline user value
- experienced reward
- cognitive burden
- privacy cost
- autonomy cost
- friction asymmetry

## Platform value proxy

Platform value is modeled as a function of:

- joining
- retention
- data extraction intensity
- engagement intensity

## Welfare-platform gap

The key diagnostic is:

```text
welfare_platform_gap = platform_value - user_welfare
```

A high gap does not prove harm, but it signals that an interface may generate institutional value while imposing user costs.

## Policy relevance

This scaffold is useful for consumer-protection, privacy, platform-governance, and behavioral-regulation analysis because it separates:

- behavioral effectiveness
- user welfare
- platform value
- autonomy costs
- distributional vulnerability
