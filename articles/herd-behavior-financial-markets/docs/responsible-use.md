# Responsible Use

Appropriate uses include behavioral-finance teaching, financial-stability research, market-risk analysis, synthetic simulation, reproducible methods demonstration, and policy-evaluation scaffolding.

Inappropriate uses include investment advice, market manipulation, coordinated trading, speculative promotion, retail-investor targeting, pump-and-dump behavior, or using the code to encourage risky financial participation.

All outputs are synthetic. They should not be interpreted as forecasts, trading signals, or claims about any specific security, asset class, market, or investor population.
