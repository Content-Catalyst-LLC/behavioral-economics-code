# Responsible Use

Appropriate uses include behavioral-economics teaching, household-finance research, synthetic simulation, consumer-protection analysis, policy-evaluation scaffolding, digital-finance design review, and reproducible methods demonstration.

Inappropriate uses include financial advice, credit product marketing, exploiting household segmentation, hidden-fee design, dark-pattern subscription design, manipulative windfall-spending prompts, or using behavioral insights to increase unnecessary debt or consumer vulnerability.

All outputs are synthetic. They should not be interpreted as financial advice, credit counseling, product recommendations, or empirical claims about real households.
