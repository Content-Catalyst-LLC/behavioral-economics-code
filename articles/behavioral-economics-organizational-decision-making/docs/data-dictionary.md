# Data Dictionary

The data in this folder are synthetic and are used only to demonstrate organizational decision-making models.

## synthetic_project_portfolio.csv

| Column | Type | Description |
|---|---:|---|
| project_id | integer | Synthetic project identifier |
| expected_payoff | numeric | Expected financial or strategic upside |
| risk | numeric | Perceived project risk |
| sunk_cost | numeric | Prior investment already committed |
| prestige_value | numeric | Internal career/status value of continuation or approval |
| complexity | numeric | Cognitive or administrative difficulty |
| overconfidence | numeric | Simulated managerial overconfidence |
| review_strength | numeric | Strength of independent review or governance challenge |
| long_horizon_value | numeric | Long-term strategic, sustainability, or resilience value |
| continue_prob | numeric | Simulated probability of continuation |
| continue_decision | integer | Simulated continuation decision |

## organizational_regime_summary.csv

| Column | Type | Description |
|---|---:|---|
| regime | text | Organizational governance scenario |
| approval_rate | numeric | Simulated share of projects approved |
| mean_approval_prob | numeric | Mean predicted approval probability |
| mean_welfare | numeric | Synthetic welfare proxy |
| escalation_prone_approval_rate | numeric | Share of projects approved under escalation-prone conditions |
