# Methods Notes

This scaffold compares stylized organizational decision regimes using synthetic data.

The models focus on:

- bounded rationality
- sunk-cost escalation
- managerial overconfidence
- prestige incentives
- metric-heavy short-termism
- conformity pressure
- review strength
- long-horizon value and sustainability-related decision weight

The examples are intentionally simple so that assumptions remain visible. They are not calibrated to a specific firm, agency, workforce, or organization.

## Conceptual model

A simplified organizational project value can be represented as:

```text
V_j = expected_payoff - risk + prestige_value - complexity + narrative_alignment
```

Continuation decisions may be distorted by sunk costs:

```text
V_cont = expected_future_payoff - risk + lambda * prior_investment
```

Independent review can reduce the weight of sunk costs, overconfidence, and prestige incentives.
