# Utility Functions Notes

## Expected utility

```text
EU = sum_i p_i u(x_i)
```

## CRRA utility

```text
u(x) = x^(1-rho)/(1-rho), rho != 1
u(x) = ln(x), rho = 1
```

CRRA models are common in macroeconomics, finance, and growth theory because they imply stable relative risk aversion.

## CARA utility

```text
u(x) = -exp(-a x)
```

CARA models are useful when absolute risk aversion is assumed constant.

## Certainty equivalent

```text
u(CE) = EU
```

The certainty equivalent is the guaranteed outcome that gives the same utility as a risky lottery.

## Risk premium

```text
Risk Premium = Expected Value - Certainty Equivalent
```

A risk-averse individual has a positive risk premium.

## Interpretation notes

- Utility curvature represents risk attitudes.
- Utility is not necessarily money.
- Expected utility is a benchmark, not a complete descriptive model.
- Welfare analysis requires distributional and ethical assumptions.
