# Portfolio Choice Notes

Expected utility provides a foundation for understanding risky asset allocation.

## Core factors

- Expected return.
- Return variance.
- Wealth.
- Utility curvature.
- Risk aversion.
- Background risk.
- Liquidity needs.
- Time horizon.
- Correlation across assets.
- Diversification.
- Trust and access.

## Behavioral departures

- Loss aversion.
- Purchase-price anchoring.
- Overconfidence.
- Availability bias after crashes.
- Herd behavior.
- Return chasing.
- Under-diversification.
- Mental accounting.
- Low participation despite positive expected equity premium.

A useful empirical workflow should compare expected-utility predictions with observed behavior under institutional and behavioral frictions.
