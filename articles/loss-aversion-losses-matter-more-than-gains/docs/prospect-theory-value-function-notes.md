# Prospect-Theory Value Function Notes

## Reference dependence

Loss aversion requires a reference point. The reference point may be current possession, expectation, prior price, purchase price, wage baseline, policy benefit, contract term, ownership, social norm, or moral entitlement.

## Stylized value function

```text
v(x-r) = (x-r)^alpha              if x >= r
v(x-r) = -lambda(r-x)^beta        if x < r
```

## Key parameters

- `lambda`: loss-aversion coefficient.
- `alpha`: gain-domain curvature.
- `beta`: loss-domain curvature.
- `r`: reference point.
- `x-r`: gain or loss relative to reference point.

## Core interpretation

When `lambda > 1`, losses have greater weight than equivalent gains.

## Cautions

- Not every negative reaction is loss aversion.
- Some losses are material and severe.
- Some reference points reflect rightful claims.
- Some reference points reflect unjust privilege.
- Some loss frames are manipulative.
- Some loss frames make hidden harm visible.
