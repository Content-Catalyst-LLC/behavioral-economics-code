# Responsible Use

Appropriate uses include applied behavioral-economics teaching, social-preference modeling, bargaining simulations, public-goods cooperation, institutional design research, labor-market fairness research, platform-governance evaluation, and reproducible documentation.

Inappropriate uses include manipulating fairness perceptions, suppressing legitimate fairness complaints, extracting cooperation without accountability, making unfair systems appear legitimate, or using social-preference parameters to rationalize exploitation.

Fairness and reciprocity research should be connected to power, constraint, institutional legitimacy, labor-market alternatives, historical inequality, public accountability, and substantive justice.
