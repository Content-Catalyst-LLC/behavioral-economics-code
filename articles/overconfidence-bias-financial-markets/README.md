# overconfidence-bias-financial-markets

Article-level computational scaffold for the Behavioral Economics knowledge series.

## Suggested contents

- Synthetic dataset in `data/synthetic/`
- Python workflow in `python/`
- R workflow in `r/`
- Julia simulation or optimization example in `julia/`
- C, C++, Fortran, Rust, and Go examples where performance, systems modeling, or CLI tooling is useful
- SQL schema or query examples in `sql/`
- Method notes and ethics notes in `docs/`
- Generated figures and tables in `outputs/`

## Scope

This folder is for reproducible educational and research-support examples. It should use synthetic data unless a future article explicitly documents a public, licensed, non-sensitive dataset.
