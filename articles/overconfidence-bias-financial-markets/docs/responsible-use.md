# Responsible Use

Appropriate uses include behavioral-finance teaching, investor-protection research, synthetic simulation, portfolio-behavior analysis, risk-governance prototyping, and reproducible methods demonstration.

Inappropriate uses include investment advice, trading advice, speculative promotion, retail-investor targeting, encouragement of frequent trading, leverage promotion, or product marketing.

All outputs are synthetic. They should not be interpreted as forecasts, trading signals, claims about any specific asset, or claims about any actual investor population.
