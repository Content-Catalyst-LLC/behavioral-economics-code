# Data Dictionary

## synthetic_trust_cooperation_panel.csv

- `agent_id`: synthetic agent identifier
- `period`: time period
- `post`: post-treatment indicator
- `regime`: assigned institutional trust regime
- `reciprocal_market_treat`: reciprocal-market treatment
- `institutional_support_treat`: institutionally supported cooperation treatment
- `trust_propensity`: baseline willingness to trust
- `reciprocity`: baseline willingness to reciprocate
- `punishment_willingness`: willingness to punish defection
- `institutional_trust`: trust in institutions
- `betrayal_sensitivity`: sensitivity to betrayal loss
- `monitoring_cost_sensitivity`: cost sensitivity to monitoring
- `trusted`: simulated trust outcome
- `reciprocated`: simulated reciprocity outcome
- `punished`: simulated punishment outcome
- `transaction_cost_reduction`: synthetic transaction-cost reduction
- `total_welfare`: synthetic welfare outcome
