# Welfare Analysis Notes

Higher trust is valuable when institutions are trustworthy and cooperation is reciprocal. Higher trust can reduce welfare when it exposes actors to exploitation, deception, or betrayal.

A stylized welfare expression is:

```text
W = cooperative_benefit + transaction_cost_reduction + punishment_value - betrayal_loss - monitoring_cost - institutional_cost
```

Key diagnostics:

- Do regimes that increase trust also improve welfare?
- Are low-trust or high-betrayal-sensitivity groups helped or harmed?
- Does institutional support reduce monitoring costs without manufacturing false confidence?
