# Responsible Use

This scaffold supports synthetic-data research and reproducible learning about choice architecture and decision environments.

Appropriate uses include:

- applied behavioral-economics teaching
- policy-evaluation methods demonstration
- welfare-analysis prototyping
- disclosure and form-design analysis
- administrative burden analysis
- consumer-protection research
- reproducible documentation practice

Inappropriate uses include:

- dark-pattern design
- manipulative defaults
- deceptive disclosure
- exploitative friction
- consent extraction
- production deployment without legal, ethical, accessibility, distributional, and empirical review

Choice architecture research should support transparency, accessibility, reversibility, proportionality, informed agency, institutional accountability, and welfare-enhancing design.
