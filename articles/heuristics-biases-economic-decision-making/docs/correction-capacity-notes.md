# Correction Capacity Notes

Correction capacity represents the ability of a decision-maker or decision environment to reduce heuristic distortion.

## Components

- Numeracy.
- Domain knowledge.
- Base-rate access.
- Clear disclosure.
- Counter-anchor context.
- Representative comparison groups.
- Decision aids.
- Time for deliberation.
- Reduced cognitive load.
- Trustworthy institutions.
- Contestability.
- Feedback.

## Design questions

- Does the intervention improve comprehension?
- Does it improve calibration?
- Does it reduce absolute error?
- Does it reduce burden?
- Does it improve welfare rather than only changing behavior?
- Does it work for low-numeracy, high-stress, or vulnerable groups?
- Is the user able to contest the choice architecture?
