# Digital Interface Framing Notes

Digital platforms frame choices through layout, labels, salience, order, ranking, defaults, and friction.

## Interface framing channels

- Button labels.
- Button color and size.
- Default-selected options.
- Ranking and search order.
- Popular-choice badges.
- Progress bars.
- Countdown timers.
- Scarcity cues.
- Push notifications.
- Recommendation systems.
- Checkout sequencing.
- Subscription cancellation flows.
- Risk warnings and confirmation screens.

## User-aligned practices

- Make material terms visible before action.
- Avoid false urgency.
- Avoid hiding decline or cancel options.
- Display total costs.
- Label recommendations transparently.
- Show risk before irreversible actions.
- Keep privacy choices clear.
- Make opt-out and cancellation straightforward.
- Test comprehension, not only click-through.

Interface framing is behavioral governance. It should be accountable.
