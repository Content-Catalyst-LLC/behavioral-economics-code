# Responsible Use

This scaffold supports synthetic-data research and reproducible learning about behavioral regulation and institutional design.

Appropriate uses include:

- applied regulatory economics teaching
- policy-evaluation methods demonstration
- administrative-burden research
- welfare-analysis prototyping
- compliance-policy analysis
- institutional design research
- reproducible documentation practice

Inappropriate uses include:

- manipulating public consent
- obscuring regulatory costs
- targeting vulnerable groups
- designing dark patterns for compliance
- replacing public justification with invisible steering
- production deployment without legal, ethical, distributional, and empirical review

Behavioral regulation should support transparency, accessibility, proportionality, institutional accountability, public legitimacy, and welfare-enhancing governance.
