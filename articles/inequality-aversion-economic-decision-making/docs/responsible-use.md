# Responsible Use

Appropriate uses include applied behavioral-economics teaching, social-preference modeling, bargaining simulations, public-economics methods, redistribution-policy analysis, wage-fairness research, and reproducible documentation.

Inappropriate uses include manipulating distributive resentment, suppressing legitimate fairness concerns, using inequality-aversion parameters to justify exploitative compensation, or treating structural injustice as merely a psychological preference.

Inequality-aversion research should be connected to power, opportunity, institutional legitimacy, labor-market constraints, historical inequality, and public accountability.
